# 泡泡 · Bloop

> **一只大部分时间在憋气的鲸鱼。**
>
> 它趴在桌面上看着你在干什么，平时憋着不出声；
> 憋够久了你才能信它——真开口的时候，吐个泡泡说一句。

名字的两层意思：鲸鱼**吐泡泡**（它的样子），它说话用的也是**气泡**（它的界面）。
而"憋着"这件事是有刻度的：它身上那个小角标写的是**「看过了，但没说」的次数**。

---

## 它是什么

不是聊天机器人，也不是"随时待命的 AI 助手"。它**不问你问题、不等你提问**——
它自己在后台看着你的屏幕，判断此刻值不值得打断你；值得就说一句，不值得就一直安静。

一句话定位：

> **在两小时里只打扰你一次，而那一次你确实需要。**

所以这个项目真正要做的不是"让 AI 能看见屏幕"，而是**让 AI 说得出「我决定不说」**。
沉默在这里不是"没有输出"的那个洞，而是一个**明确的、可被观察的输出**——
宠物身上那个"看过了但没说"的计数角标，就是把它做出来给人看的地方。

## 为什么不是"又一个 AI 助手"

对话式工具都要求同一件事：**用户得先知道"我卡住了"，而且手里有余力开口**。
但在真实执行任务时，这两个前提经常同时不成立：

| 结构性失效 | 场景 |
|---|---|
| **来不及问** | 双手被占（做菜、修理）、正在通话、深度操作中 |
| **不知道自己卡住了** | 同一字段试三次、顺序搞反、资料不齐就开始 |
| **上下文要重述** | "我填到哪了""我手上有哪些料" |

这个项目就是在**这两个前提都不成立**的地方工作的。

| [`ambient-guide/`](ambient-guide/) | 早期 DSH 插件形态 | **已停用**，保留作历史（结论见下） |

> **为什么从 DSH 里搬出来**：在 DSH 里做的时候发现，DSH 的操作模型本来就看得见，
> "把它折叠成一句摘要"的增量只剩时间行为，价值不足。桌面上模型完全看不见——
> 那才是这个能力真正该在的地方。

## 快速开始（PowerShell 版）

```powershell
pwsh -NoProfile -ExecutionPolicy Bypass -File .\desktop-guide\DesktopGuide.ps1
```

需要 **PowerShell 7**。第一次用语音输入时会按需下载 SenseVoice 模型（约 229MB，本机离线识别）。

| 操作 | 效果 |
|---|---|
| 左键点它 | 现在说一句 |
| **长按**它 | 说话（松开就识别，和打字走同一条管线） |
| 双击它 | 打断（停朗读 + 取消这次思考） |
| 拖东西给它 | 当成任务派出去做 |
| 右键 | 对话 / 打字派活 / 语音输入 / 设置 / 账本 / 退出 |
| Ctrl+Alt+G · Ctrl+Alt+T | 「现在说一句」·「打字派活」 |

细节都写在 [`desktop-guide/README.md`](desktop-guide/README.md)——很长，但每个"为什么"都在里面。

## 已经踩实的设计决定

这些不是规划，是**实测过、推翻过、重来过**之后留下的：

| 决定 | 为什么 |
|---|---|
| **门控是本地代码，不是模型** | 前沿模型判"何时该介入"通过率 <50%。"值不值得问"由本地判据决定（画面变了没、窗口换没换、人还在不在），模型只负责"说什么" |
| **采样率跟着任务走，采样即截图** | 卡牌 0.6s / 视频 8s / 桌面 10s。采样率就是"多久看一眼"，而看就必须带图——没有图的判断只能靠窗口标题猜，信息量近乎为零 |
| **用户操作优先级最高** | 你一动它，正在跑的自动判断立刻让位；停手 6 秒后它自己接着做。双击打断则**不**补做（说要停就停） |
| **黑屏 / 锁屏 / 睡眠 = 待机** | 直接读系统信号（显示器电源 / 会话锁 / 睡眠），而不是等抓屏失败刷警告；醒来先作废过期观测，避免把"静止 8 小时"喂给模型 |
| **一个常驻运行时 + 统一的会话** | 原来每轮都起一个完整进程（8–25 秒）；改成常驻后每轮 **0.9–1.5 秒**，记忆跨轮延续 |
| **一个会话只能有一个写入者** | 两个写入者互抢句柄；"已在别处打开"要翻译成人话告诉用户，而不是抛黑话 |
| **用最弱的够用机制** | 能本地判断的绝不花模型；能静默记账的绝不插话 |

## 商业化：老实说，很难单独赚钱

这不是谦虚，是几条被想清楚（并写进总纲）的硬约束：

1. **消费者不会为"桌宠"付钱。** 桌面宠物的历史是"装完炫两天然后删掉"，
   原因永远是同一个——**只有表达，没有判别**。要收钱，得先证明判别是真的。
2. **"帮判断"卖不动，"省时间"和"留痕"才卖得动。** 有实证：AI 文书助手每天省 13 分钟 EHR、
   16 分钟文书，而**下班后时间没有显著差异**——效应是 modest 的，按"省时间"定价撑不住。
3. **让雇主看见自己人的失误，会死在内部政治上。** "AI 已提醒未处置"的留痕，
   对买方是**负债**而不是保险。这条一票否决了一整类 B 端方向。
4. **没有响应者的提示是负资产。** 它训练用户忽略所有提示（Andon 的教训：响应速度是唯一自变量）。

**可能成立的几条路**（都还没验证）：

- **不单独卖，嵌进别人已经在付费的工作流**：作为 IDE / 通话软件 / 行业软件里的一个能力。
  用户不为"泡泡"付钱，为那个宿主付钱。
- **卖"什么时候该沉默"的标注数据**：总纲的判断是——**护城河在标注数据上，不在模型上**。
  但这需要量、需要同意、也需要有人买。
- **把场景收窄到"漏掉代价高、且责任人明确"的地方**：远程陪诊、口播合规提示之类。
  判据是总纲里的六道门控，最硬的一条是 **G3 状态可读（SL ≥ 3）**——
  决定成败的那 1% 恰好是你观测不到的那 1%，这类方向一票否决。

**最短的证伪路径**：找一个"漏掉某一步会付出明确代价"的具体场景，跑两周，只看两件事：

1. **沉默率**是不是稳定落在 30%–70%（说明它真的在分辨，而不是总找得到话说）
2. 有没有**一次**用户因为它开口而改变了行为

这两条都拿不到，就不要谈商业化了。
