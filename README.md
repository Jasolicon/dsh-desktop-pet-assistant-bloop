# 泡泡 · Bloop

**一只趴在桌面上的鲸鱼。它看着你干活，大多数时候什么都不说。**

真该开口的那一次，它吐个泡泡说一句 —— 或者你按住它说话、打字、把文件丢给它，它就去把事情做了。

---

## 它到底解决什么

用 AI 的人都会遇到同一件事：**你得先知道自己卡住了，还得有余力开口**。

可你在做菜、在修东西、在开会、在赶一个表格的时候，这两个前提经常同时不成立 ——
手占着、注意力占着，于是你既想不到要问，也腾不出手去问。

泡泡补的正是这一段：

| 常见的失效 | 泡泡的做法 |
|---|---|
| 来不及问（手被占着 / 正在通话） | 它自己看，你不用开口 |
| 不知道自己卡住了（同一件事试了三遍） | 它看着你试，试到第三次它说一句 |
| 每次都要重述背景 | 它记着今天看过什么，不用你重新交代 |

它一次只说一句。**大多数时候它什么都不说** —— 这不是没找到话说，是它判断过、决定不说。

## 它会说 / 它不会说

下面这些是它真说过、真沉默过的（来自它自己的判断日志）：

**它会说的：**

> 「两个桌宠叠一起时按钮会互相抢点击 —— 确认旧实例真的退出了没有。」
>
> 「鼠标悬停时倒计时要暂停，否则你正要点击的瞬间按钮就消失了。」
>
> 「同一个循环整理第三遍了，上面的判断可以合并。」

**它会闭嘴的**（连"理由"都会记下来）：

> *「任务正在正常跑、你在等它 —— 这属于正常等待，没有可证明的错误。」*
>
> *「你只是在阅读文档。」*
>
> *「屏幕上没什么异常，我也说不准在发生什么。」*

沉默不是"没有输出"，而是一次**判断的结果**。这是它和所有"随叫随到"的 AI 最大的区别。

## 怎么用

它在桌面上就是一只会眨眼的小宠物。**点一下**＝让它看一眼现在说句建议；**长按**＝你说话；
**打字**＝派活给它；**拖东西**到它身上＝当成任务交出去。

| 操作 | 效果 |
|---|---|
| 左键点它 | 现在看一眼，说句建议 |
| **长按它** | 你说话（松开就识别）—— 「帮我把那个 docx 第三段加粗」也行 |
| **Ctrl+Alt+T** | 打字派活（和说话走同一条管线） |
| 双击它 | 打断（停朗读；正在想也一起取消） |
| 拖文件 / 文字给它 | 交给它做 |
| 右键 | 对话 / 打字 / 语音 / 设置 / 账本 / 退出 |
| Ctrl+Alt+G | 同「点它一下」 |

**朗读**：它说的结论句会读出来（微软 Edge 神经音色，可换、可静音）。

**账本**：气泡最下方一行小字**一直**写着「余额 · 上次调用花了多少 · 今天花了多少」；
余额涨了（有人充值）它会说一声，每 30 分钟也会主动报一次。

**对话**：想长篇聊，右键「对话」直接开 DSH 自己的界面。

## 装

```powershell
pwsh -NoProfile -ExecutionPolicy Bypass -File .\desktop-guide\DesktopGuide.ps1
```

| 需要 | 说明 |
|---|---|
| **PowerShell 7** | Windows 自带的是 5.1，脚本会明确提示你换 |
| **DeepSeek Harness** | 它把 DSH 的 agent 当"大脑"（用你已登录的账号，不用另配 key） |
| 语音输入（可选） | 首次使用按需下载 SenseVoice 模型，约 229MB，**本机离线识别** |

不需要 Docker、不需要 Node、不需要单独申请模型 key。

## 它不做什么

这一节是刻意的 —— 一个"随时在旁边"的东西，边界比功能更重要：

| 不做 | 为什么 |
|---|---|
| 不监听键盘输入 / 不读剪贴板 / 不记录窗口里的文字 | 侵入性太强，对判断帮助也有限 |
| 不抢焦点 | 它能点、能拖，但永远不激活、不打断你 |
| 不把截图落盘 | 只在内存里留最近几张，落盘的只有窗口标题 / 进程 / 时间 |
| 不在你忙的时候插话 | 你一动手它就立刻让位；黑屏 / 锁屏 / 睡眠它直接待机 |
| 不写"什么时候该说"的死规则 | 该不该说由可测试的本地判据决定，说什么才交给模型 |

## 它是怎么做到的（给好奇的人）

一句话：**"要不要说"由本地代码判断，"说什么"才交给模型。**

模型在"什么时候该介入"这件事上通过率不到一半，所以门控必须是确定性的代码、而且可穷举单测；
模型只在放行之后，负责把那句话写好。这条分工是整个项目的地基。

具体到工程细节 —— 采样率跟着任务走（卡牌 0.6 秒 / 视频 8 秒）、采样即截图、用户操作优先级最高、
黑屏即待机、一个常驻运行时把每轮从 9 秒压到 1 秒、每次调用花了多少钱 ——
都写在 **[desktop-guide/README.md](desktop-guide/README.md)** 里，
包括每个决定当初为什么这么定、以及被实测推翻过什么。

产品层面的判断（为什么砍掉早期形态、方向与证据）在 **[随时指导项目_总纲.md](随时指导项目_总纲.md)**。

**已知限制**（说清楚，不美化）：

- 只在 Windows 上跑；还没做托盘图标和开机自启
- 多显示器只抓主屏；全屏独占程序（部分游戏）抓不到
- 语音识别是"整句"的，不是边说边出字
- 判断准不准，取决于它对"什么算异常"的理解 —— 这也是它唯一值得持续调的地方

## 关于商业化

直说：**单独卖，很难。**

桌面宠物的历史是"装完炫两天然后删掉"，死因永远是同一个 —— 只有表达，没有判别。
消费者也不会为"帮判断"付钱；能卖的是"省时间"和"留痕"，而有实证表明这类效应是 modest 的。

它更可能的活法，是作为一个能力**嵌进你已经在付费的工作流**里（编辑器、通话软件、行业软件），
而不是独立产品。

但它真正值钱的东西不在代码里：是它一次次**"决定不说"**、以及你**因为它开口而改了做法**的记录。
这条数据攒起来之前，谈商业化都是空谈。
